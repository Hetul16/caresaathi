# Risks, fallbacks and sources (original plan sections 16 and 17)

> **Note (Oct 24, 2026):** Original text. The cut order in `05-scope.md` is more aggressive than the one in the risks table and supersedes it if accepted.

## 16. Risks and fallbacks

| Risk | Fallback |
| --- | --- |
| WhatsApp setup not approved in time | In-app chat screen that looks and behaves the same; show WhatsApp as the launch plan |
| TTS sounds poor in Marathi | Test options before Day 1; fall back to Hindi or English voice for the demo with Marathi text on screen |
| Speech recognition weak on medicine names | Read-back confirmation and matching against the written prescription |
| Credits run out | Cheaper model for development; trim context; cut lower-priority features |
| Behind schedule | Cut in this order: glasses Level 2, SAM 3.1 photo check, shared schedule, cost help |
| Wound photos are hard to compare fairly (lighting, angle) | Guide the patient with an on-screen outline and a consistent distance; in the demo, use staged photos taken the same way each time |
| Drug-family list incomplete | Keep it focused on common allergies, have a doctor or pharmacist review it, and always tell families to confirm with a pharmacist |
| API outage during recording | Recorded backup clips for every demo step |
| Team member unavailable | Each feature documented in the README so others can take over |
